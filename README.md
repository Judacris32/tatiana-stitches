# Tatiana Stitches

Website for Tatiana Stitches, the Onitsha tailoring house of Chigbo Vitalis Agbo. Built by JayDev Studio.

## Stack
Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, Lucide icons. Fonts are bundled with Fontsource (Marcellus, Cormorant Garamond, Jost), so the build never needs to reach Google Fonts.

## Run it
```
npm install
npm run dev
npm run build
```
